
# Bagian 2 — Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| **Bahasa utama** | HTML, CSS, JavaScript, serta bahasa backend seperti PHP dan Python. | C#, C++, Java, Python, dan Swift. | Kotlin dan Java (Android), Swift (iOS), serta Dart (Flutter). |
| **Arsitektur** | Menggunakan arsitektur client-server. Aplikasi diakses melalui browser yang berkomunikasi dengan server menggunakan HTTP/HTTPS. | Berjalan secara lokal pada komputer dan memanfaatkan sistem operasi serta sumber daya perangkat. Dapat bekerja secara offline maupun terhubung ke server. | Berjalan pada sistem operasi perangkat mobile seperti Android dan iOS. Dapat menggunakan penyimpanan lokal, API perangkat, dan koneksi server. |
| **Cara distribusi** | Diunggah ke web server atau hosting dan diakses melalui URL menggunakan browser. | Didistribusikan melalui file installer seperti `.exe`, `.msi`, atau toko aplikasi desktop. | Didistribusikan melalui Google Play Store, Apple App Store, atau metode instalasi resmi lainnya. |
| **Keunggulan** | Mudah diakses melalui berbagai perangkat, tidak perlu instalasi, dan pembaruan dapat dilakukan langsung pada server. | Memiliki akses lebih luas terhadap sumber daya komputer, performa baik untuk pekerjaan kompleks, dan dapat digunakan tanpa internet. | Praktis digunakan kapan saja, mudah dibawa, serta dapat memanfaatkan fitur perangkat seperti kamera, GPS, dan notifikasi. |
| **Keterbatasan** | Bergantung pada browser dan koneksi internet untuk fitur tertentu. Akses terhadap perangkat keras lebih terbatas dibandingkan aplikasi native. | Membutuhkan instalasi, dapat bergantung pada sistem operasi tertentu, dan memerlukan pembaruan aplikasi secara berkala. | Terbatas oleh ukuran layar, kapasitas baterai, dan sumber daya perangkat. Pengembangan juga perlu menyesuaikan berbagai tipe perangkat. |
| **Contoh aplikasi** | Google Docs, Gmail, YouTube, dan sistem informasi akademik berbasis web. | Microsoft Word, Adobe Photoshop, Visual Studio Code, dan VLC Media Player. | WhatsApp, Instagram, Google Maps, dan aplikasi mobile banking. |
